## Isi Source

- `case1-countletters/`: menghitung frekuensi huruf dengan penanganan karakter nonhuruf.
- `case2-parseints/`: menjumlahkan integer dan melewati token noninteger.
- `case3-factorial/`: menghitung factorial untuk input 0-16 dengan penanganan argumen invalid.

## Cara Menjalankan

Jalankan dari folder yang berisi `source/`.

```bash
javac source/case1-countletters/CountLetters.java
java -cp source/case1-countletters CountLetters

javac source/case2-parseints/ParseInts.java
java -cp source/case2-parseints ParseInts

javac source/case3-factorial/Factorials.java source/case3-factorial/MathUtils.java
java -cp source/case3-factorial Factorials
```
